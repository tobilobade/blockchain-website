# **Blockchain Movie Ticket Website**

## **Overview**
Welcome to the **Blockchain Movie Ticket Website** project! This repository hosts the source code for a decentralized movie ticket booking platform leveraging blockchain technology. The project integrates blockchain for secure, transparent, and tamper-proof ticket booking, ensuring reliability and trust for both users and organizers.

---

## **Features**
- **Decentralized Ticketing**: Secure and transparent movie ticket booking powered by blockchain technology.
- **Smart Contract Integration**: Automated ticket validation and transaction management using Ethereum smart contracts.
- **User-Friendly Interface**: Intuitive UI/UX for browsing movies, selecting seats, and booking tickets.
- **Blockchain Security**: Immutable and auditable records of all transactions.
- **Scalability**: Designed to handle a large number of users with minimal latency using a hybrid blockchain architecture.
- **Payment Integration**: Support for cryptocurrency payments for ticket purchases.

---

## **Technology Stack**
- **Frontend**: HTML, CSS, JavaScript.
- **Smart Contracts**: Solidity-based contracts deployed on Ethereum (or compatible blockchains like Sepolia or Polygon).
- **Blockchain**: Ethereum network (Testnet: Sepolia).
- **Backend**: Node.js with Web3.js for blockchain interactions.
- **Database**: SmartContracts acted as the database.
- **Deployment**: Aws Beanstalk.
